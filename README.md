An entry for the make.fun bounty [Midnight Fridge Roast](https://make.fun/c/u-carbon-forge-midnight-fridge-roast-fc5d44a7): one line roasting a smart fridge that refuses to open after midnight. The program (`main.py`, stdlib only, no network) writes the line to `/output/entry.txt`.

> My smart fridge locks at midnight because a sandwich at 12:01 is, in its opinion, a cry for help.

Run: `python3 main.py`
